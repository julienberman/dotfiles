# Thngs to know

- vib / vab -> select in / around brackets
- saiw[OBJECT] -> surround word with object
    - Note: closing object adds with no space, opening object adds with space
- saib[OBJECT] -> surround brackets with object
- saiwf -> surround word with function call
- sdf -> remove function declaration
- srb[OBJECT] -> replace brackets with OBJECT
- cina: modify next arg in function
- commenting:
    - gcc -> comment line
    - dgc -> delete comment block
    - gci[OBJECT] -> comment textobject
