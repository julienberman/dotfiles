### Tmux config

Terminal multiplexer

### Installation
- Macos
```
brew install tmux
```

- Archlinux:
```
sudo pacman -S tmux 
```

### Pacakges
- Create a `plugins` folder in `~/.config/tmux`
- Create a subfolder of `plugins` called `tpm`
- Clone tpm: `git clone https://github.com/tmux-plugins/tpm`
- Create a subfolder of `plugins` called `catppuccin`
- Clone catppuccin: `git clone -b v2.1.3 https://github.com/catppuccin/tmux.git ~/.config/tmux/plugins/catppuccin/tmux`
